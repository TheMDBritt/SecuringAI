## Domains (user-transcribed, unweighted)

### 1. Securing Access and Identity
Managing identities via Microsoft Entra ID, Conditional Access, and Privileged Identity Management (PIM).

### 2. Securing Infrastructure and Compute
Hardening virtual machines, network perimeters (Hub-and-Spoke), and Azure Kubernetes Service (AKS).

### 3. Securing Storage, Databases, and Networking
Protecting data at rest and in transit across cloud resources.

### 4. Securing AI Solutions and Governance
Defending AI/copilot workloads against jailbreaking, data inversion, and prompt attacks using Microsoft Purview and security guardrails.

### 5. Managing and Monitoring Security Posture
Utilizing Microsoft Sentinel, KQL analytics rules, and Defender XDR.
